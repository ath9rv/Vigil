Privacy Policy — Vigil

Extension: Vigil — Web Trust & Safety Shield
Effective Date: September 8, 2026
Architecture: Client-Side Local Execution · Zero Analytics

1. Core Commitment

Project Vigil is built on an absolute, non-negotiable architectural invariant: a browser trust and safety tool must never become a surveillance or tracking vector.

  • No browsing history is collected, transmitted, or stored on remote servers — ever.
  • No keystrokes, form inputs, passwords, or credentials are monitored, captured, or transmitted.
  • Zero third-party analytics SDKs: Vigil contains no Google Analytics, Mixpanel, Segment, Datadog, Sentry, or PostHog.
  • Zero tracking identifiers: Vigil does not create cross-session IDs, device fingerprints, or advertising beacons.
  • Local storage only: All user settings and score caches reside exclusively in chrome.storage.local on your device.

2. 100% On-Device Processing

Every core security, privacy, and heuristic scanning pipeline in Vigil executes locally on your CPU and inside browser memory:

Pipeline What It Does Execution Location
DOM Dark-Pattern Scanner Detects deceptive design (drip pricing, fake countdown urgency, pre-ticked subscription traps) Local CPU / In-Memory
Behavioral Cookie DNA Analyzes cookie Shannon entropy, expiration, and security flags (Secure, HttpOnly, SameSite) Local CPU / In-Memory
Credential Shield Detects typosquatting, homoglyphs, and form-action mismatches before credential dispatch Local CPU / In-Memory
Anti-Fingerprinting Perturbs Canvas, WebGL, and AudioContext readbacks with deterministic noise Local Page Context
Legal Document Auditor Classifies terms of service and privacy policies across 19 risk vectors using an on-device NLP parser Local CPU / In-Memory
WebRTC Protection Configures interface policy to block STUN/ICE local IP address leakage through VPNs Browser Network Stack

Raw cookie values, authentication tokens, and user inputs are strictly discarded after entropy/flag calculation and are never persisted or exported.

3. External Network Requests & Call-Site Consent Invariant

By default, Vigil dispatches zero outbound network requests during installation, startup, background operations, or browsing.

Optional Third-Party Integration: ToS;DR Phoenix API

Vigil provides an optional deep legal audit feature powered by the open-source ToS;DR (Terms of Service; Didn't Read) database.

  • Default State: OFF (Disabled). Vigil relies exclusively on its on-device legal parser.
  • Call-Site Consent Enforcement: Consent is verified directly at the network execution point (tosdr-client.ts), not merely in the UI. No network socket can open without explicit user consent.
  • Data Sent (When Explicitly Consented): HTTPS GET to https://api.tosdr.org/service/v1/?url=<domain> transmitting only the public registered domain name (e.g. example.com). Full URLs, paths, query parameters, referrers, cookies, and user IDs are strictly excluded (credentials: 'omit').
  • Instant Cache Purge on Revocation: Revoking consent immediately deletes all cached ToS;DR data for that domain from chrome.storage.local and halts all outbound queries.

4. Extension Permissions Explained

Permission Purpose & Safeguard
host_permissions: ["<all_urls>"] Required to analyze page DOM structures for dark patterns, credential theft forms, and tracker scripts on visited sites. All processing is strictly in-memory and client-side.
declarativeNetRequest Blocks network requests to 100+ known tracking, advertising, and fingerprinting domains using Chrome's native engine.
declarativeNetRequestWithHostAccess Strips tracking query parameters (such as fbclid, gclid, utm_*) via native redirect transformations without executing JavaScript.
declarativeNetRequestFeedback Reads rule match counts via getMatchedRules() solely to display blocked tracker statistics in the popup UI. No browsing history or URLs are recorded or transmitted.
storage Stores local configuration, allowlists/denylists, and cached scores in chrome.storage.local on the user's disk.
cookies Read-only inspection of cookie metadata (lifespan, security flags, entropy) to identify pre-consent tracking cookies. Raw values and session tokens are never saved or sent.
scripting Injects the anti-fingerprinting script (defender.js) into the page main world to neutralize device fingerprinting.
privacy Sets webRTCIPHandlingPolicy to default_public_interface_only to prevent private LAN IP leakage through VPN tunnels. Does not touch any other browser settings.
activeTab Grants temporary access when the popup is opened to highlight detected deceptive elements in the DOM.
notifications Displays local desktop alerts when critical typosquatting or credential theft forms are detected.

5. Content Security Policy

script-src 'self'; object-src 'self'

Vigil enforces a strict Content Security Policy forbidding remote script evaluation, eval(), and CDN script loaders. All code runs from within the packaged extension.
