# Product Documentation

This area documents the transition from a certified technical engine to a real-world product.

The current phase is **Product & Real-World Validation**.

The priority is refinement, not architecture expansion:

- improve first-run and zero-state UX;
- make explanations understandable to non-technical users;
- provide a safe feedback loop for misclassifications;
- refine accessibility and responsive behavior;
- validate against the open web;
- complete release/store hardening.

The product promise remains:

> **Vigil doesn't just warn you. It shows you the receipts.**
