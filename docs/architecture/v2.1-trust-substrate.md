# Vigil V2.1 Trust Substrate Specification

This document details the hardened Layer 0 (Runtime Safety) and Layer 1 (V2.1 Trust Substrate) architecture.

---

## 1. Architectural Philosophy

The V2.1 Trust Substrate serves as the **unbreakable runtime base** upon which higher-level cognitive reasoning layers operate. It enforces three core axioms:

1. **Detection Authority ≠ Mutation Authority**: Finding a suspicious element gives zero right to mutate the DOM.
2. **Evidence ≠ Intent**: Raw observations are immutable facts; explanations are hypotheses.
3. **Transactions are Context-Bound**: Mutations and observations are fenced strictly by navigation and origin.

---

## 2. Invariant Contracts

### RawObservation (Sealed Contract)
Every sensory input enters the TrustEngine as a deeply sealed `RawObservation`:

```ts
export interface RawObservation {
  readonly id: string;
  readonly observationId?: string;
  readonly tabId: number;
  readonly navigationId: string;
  readonly timestamp: number;
  readonly sourceType: 'DOM' | 'NETWORK' | 'DOCUMENT' | 'STORAGE' | 'THREAT_INTEL';
  readonly source: string;
  readonly payload: Readonly<Record<string, unknown>>;
  readonly collector: string;
  readonly collectorVersion: string;
  readonly provenance: Readonly<ObservationProvenance>;
}
```

- **Immutability:** Runtime-enforced via `Object.freeze`.
- **Defensive Copying:** Payloads and provenance records are shallow-copied before sealing to prevent caller mutation leakage.
- **Factory Gate:** All observations must originate from sanctioned `ObservationFactory` methods.

### ReadOnlyEvidenceGraph (Reasoning Consumer Boundary)
V4 reasoning engines interact with the graph strictly through a read-only snapshot:

```ts
export interface ReadOnlyEvidenceGraph {
  readonly navigationId: string;
  getNode(id: string): Readonly<EvidenceNode> | undefined;
  getNodes(): readonly Readonly<EvidenceNode>[];
  getNodeProvenance(nodeId: string): Readonly<EvidenceProvenance> | undefined;
  getSourceObservation(nodeId: string): Readonly<RawObservation> | undefined;
  getNodeTrace(nodeId: string): Readonly<NodeTrace> | undefined;
  getConnectedSubgraph(startNodeId: string): Readonly<EvidenceSubgraph>;
  getNeighborsByRelation(nodeId: string, relation: EvidenceRelation, direction?: 'IN' | 'OUT' | 'BOTH'): readonly Readonly<EvidenceNode>[];
  getNodeCount(): number;
  getEdgeCount(): number;
}
```

- **Zero Mutation APIs:** Contains no `addNode`, `addEdge`, or `pruneNavigation` methods.
- **Node Sealing:** All returned nodes and node arrays are frozen.
